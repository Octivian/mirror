# 单店模型诊断器交付说明

这是双模块交付包中的第一个功能模块，面向蛋糕店、面包店、综合烘焙门店的新店测算。当前版本为纯前端单页工具，不依赖后端，不保存用户数据。

## 交付文件

- `index.html`：可直接运行的完整网页模块，包含首页、正式填写清单、示例演示、结果输出和导出能力。
- `coze-integration-spec.md`：给 Coze 集成使用的入口、事件、字段和输出说明。
- `schema.json`：输入和输出字段结构，可用于 Coze 工作流参数配置。
- `sample-case.json`：示例演示使用的假案例数据。

## 推荐集成方式

1. 网页嵌入：团队直接把 `index.html` 作为一个独立页面或 iframe 页面接入 Coze 对外页面。
2. 工作流拆分：把 `schema.json` 里的输入字段配置成 Coze 收集节点，再把当前 `index.html` 中的计算逻辑迁移为一个前端或服务端函数节点。
3. 混合方式：Coze 负责入口、咨询和结果解读，诊断器网页负责收集、计算、复制摘要、导出情景表。

## 当前交互

- `开始测算`：进入正式填写清单，表单为空白，用户提交后才展示结果。
- `查看示例`：进入示例演示页，顶部展示已填好的假案例输入，下面展示对应结果。
- `返回首页`：回到模块首页。
- `复制摘要`：复制诊断摘要，方便发送给客户、合伙人或内部团队。
- `导出情景表`：导出保守、基准、冲刺三个情景的 CSV 表。

## 运行方式

直接打开 `index.html` 即可运行；如果集成到站点里，也可以放在 `/store-diagnostic/` 路径下访问。
