# Coze 集成说明

## 模块定位

单店模型诊断器是一个“新店是否值得继续推进”的决策辅助模块。用户填写门店基础信息、选址投入、收入假设、周边参照和成本假设后，页面输出红黄绿灯判断、关键差距、收入建议、成本建议和情景表。

页面中不直接暴露内部判断口径，只呈现用户需要填写的内容和系统输出的结论。

## 建议入口

- 入口名称：单店模型诊断器
- 适用用户：蛋糕店老板、面包店老板、开店筹备人、门店顾问
- 入口动作：
  - 开始测算：进入空白正式填写清单
  - 查看示例：展示完整假案例输入和结果

## Coze 页面集成

如果 Coze 最终页面支持嵌入网页，建议直接嵌入：

```html
<iframe src="/store-diagnostic/index.html" title="单店模型诊断器"></iframe>
```

嵌入时建议给 iframe 至少 `100%` 宽度和 `900px` 以上高度；移动端可让页面独立打开。

## Coze 工作流集成

如果要拆成 Coze 工作流，建议按以下节点组织：

1. 收集输入：按 `schema.json` 的 `input` 字段收集。
2. 计算节点：复用 `index.html` 里的收入、成本、回本和情景计算逻辑。
3. 输出节点：按 `schema.json` 的 `output` 字段返回判断结果。
4. 展示节点：把结果渲染成卡片、建议列表和情景表。

## 输入分组

- 门店基本情况：项目名称、门店类型、经营结构
- 选址和投入：面积、月租金、总投资额、座位数
- 收入假设：日翻座、到店客单、外送单量、外送客单、自提预订单、自提客单
- 周边参照：最好门店月坪效、较弱门店月坪效、周边日均客流、截流成交率
- 成本假设：食材成本率、人力成本率、其他费用率、平台费率、包材成本率、折扣影响、折旧摊销年限

## 输出字段

- 综合结论：绿灯、黄灯、红灯
- 基准月营收
- 月保本点
- 租金率
- 回本周期
- 保本差距
- 安全租金区间
- 2 年回本所需月营收
- 优先调整变量
- 输入质量提示
- 收入优化建议
- 成本优化建议
- 三档情景表

## 重要约束

- 当前版本不保存数据，也不向后端传输数据。
- 正式测算表单必须为空白，避免用户把示例数据误当作自己的数据。
- 示例演示可以预填假案例，但要明确显示“这是示例输入”，并与正式测算路径区分。
