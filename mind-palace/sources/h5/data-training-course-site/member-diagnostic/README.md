# 会员运营诊断器交付说明

这是一个面向蛋糕店、面包店、综合烘焙门店老板的会员运营自检模块。当前版本为纯前端单页工具，不依赖后端，不保存用户数据。

## 交付文件

- `index.html`：可直接运行的完整网页模块，包含首页、正式填写清单、示例演示、结果输出、复制摘要和导出得分表。
- `coze-integration-spec.md`：给 Coze 集成使用的入口、事件、字段和输出说明。
- `schema.json`：输入和输出字段结构，可用于 Coze 工作流参数配置。
- `sample-case.json`：示例演示使用的假案例答案。

## 当前交互

- `开始自检`：进入正式填写清单，所有题目默认不选择，提交后才展示结果。
- `查看示例`：进入示例演示页，顶部展示已填好的假案例答案，下面展示对应结果。
- `返回首页`：回到模块首页。
- `复制摘要`：复制诊断摘要，方便发给客户、合伙人或内部团队。
- `导出得分表`：导出 6 个板块的得分 CSV。

## 输出内容

- 综合结论：红灯、黄灯、绿灯
- 健康度得分：满分 100 分
- 当前阶段：探索期、成长期、进阶期、领跑期
- 最大短板：按 6 个板块完成度判断
- 优先动作：给出门店下一步最该做的动作
- 板块表现：会员基础、价值感知、积分规则、新人礼拉新、触达能力、运营经验

## 推荐集成方式

1. 网页嵌入：团队直接把 `index.html` 作为独立页面或 iframe 页面接入 Coze 对外页面。
2. 工作流拆分：把 `schema.json` 的题目配置成 Coze 收集节点，再把当前页面里的评分逻辑迁移成函数节点。
3. 混合方式：Coze 负责入口、咨询和解释，诊断器网页负责填写、计算、复制摘要、导出得分表。
