## 三、 四间房 × 13 组空间结构（78 张卡片）

1. **房间 01｜工作（Work）**
   - `客户判断`：在跑客户（阿豆给、绿汀）与已结案样本（圆鹿鹿、历任主责项目）的核心判断与下一步待办。
   - `口径与判断标准`：数据口径与交付规范（应收/实收/核销三组不混、表下必写口径注）、同业复盘样本库（FLR 生死线锚点）。
   - `固定机制`：周报/月报固定机制、客户经营复盘 Skill、客户交付 PPT 版式规范（`cake-ppt-layout`）、运营中台架构拆解。
2. **房间 02｜写作（Writing）**
   - `人设与边界`：阿厘的生意草稿定位、写作偏好画像（`mirror-writing`）、脱敏铁律。
   - `选题与代表作`：每日选题候选技能、已发布代表作、唯一发布与数据台账。
   - `视觉与排版`：公众号排版（`gzh-design`）、视觉设计路由（`graphic-design` 及三大分流风格）。
3. **房间 03｜工具（Tools）**
   - `装进 Agent 的诊断技能`：自建专家包（权益卡复盘）、抖音达人筛号、小红书筛号、商品销量诊断、折扣率·毛利四象限模型。
   - `情报与检索`：**烘焙 × 茶饮垂类情报台**（60 天滚动窗口，每周一早上 09:00 自动刷新，仅保留上新/开店/营销/大促四类有据可查动作）。
   - `蛋糕经营交付流水线`：主线 01–10 步（品牌诊断 → 九宫格与六引擎 → 规划总入口 → 四季路线 → 月度节日排期 → 月度经营计划 → 渠道增长 → 渲染呈现 → 九格 H5）+ 支线（大活动五阶段策划、全案提案）。
   - `独立小工具与外部方法`：订单配送热力图、MiniMax 音色克隆 H5、李继刚圆桌会议等。
4. **房间 04｜我自己（Self）**
   - `我是怎么工作的`：USER.md 画像、与 AI 协作的铁律（INTJ，要判断和现场，不要说教与咨询腔）、宫殿更新与收拢机制。
   - `还在想的事业问题`：第二职业曲线深度推演、四道未闭环命题（Go BIG 还是小而美）、九格经营产品化评估。
   - `经历与自留地`：两年半成长脉络与半年/年终复盘、流浪猫《太君》与底层操作系统（`定点共情 × 风险预算 × 资源排序 × 行动边界`）。

## 四、 自动化与持续更新机制

1. **情报平台每周一 09:00 自动刷新**：
   - 脚本位置：`/Users/a15608/Desktop/我的工作资料库/vault/情报平台/refresh_weekly.py`
   - 规则：自动剔除超过 60 天的旧情报，仅保留近 60 天内 `newproduct / store / marketing / promo` 四类动作，严守日期四档精度与品牌口径标注，刷新后自动同步至 `sources/h5/情报平台/index.html` 与 `思维宫殿.html`。
2. **思维宫殿日常对话收拢机制（四要素确认单）**：
   - 触发节点：单次深度交付拍板后、或每周五/周日轻量盘点时。
   - 写入前必经确认：向 Mirror 出具**【① 放进哪间房哪一组 / 更新哪张卡 ② 500 字以内核心概括 ③ 新增或勾掉的待办 ④ 关联真源文件路径】**，经回复「准 / ok」后方可落盘，严禁静默篡改判断层。
