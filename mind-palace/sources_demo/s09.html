# 蛋糕品牌经营诊断

你只负责诊断，不生成月度任务。诊断目标是回答：品牌在什么样的市场中、相对于当地竞争处于哪个阶段、渠道能力是真实的还是自评偏差。

## 输入

优先复用对话中已知数据。缺少时，按 3 个题组收集：

### 题组 A：城市

- 让用户自由填写城市，不给默认城市。
- 将城市归为高线、中线或下沉市场。
- 分类不只看行政级别，还要看市场空间、消费密度、本地生活渠道重要性和内容投放成本。
- 无法确定时给出“暂定中线，低信心”等明确信心度，不把城市判定伪装成确定事实。

### 题组 B：规模与当地位置

- 品牌月营业额：`10 万以内 / 10-30 万 / 30-50 万 / 50-100 万 / 100 万以上`。
- 经营形态：`非连锁 / 小型连锁（2-3 店）/ 连锁（4 店及以上）`。
- 门店数：记录实际值，用于履约、组织与装置布景估算。
- 当地同类位置：让用户在与自己相同的连锁/非连锁类型中自评 `前 30% / 31%-50% / 51%-80% / 后 20%`。

绝对营业额不能覆盖本地相对位置。例如中线城市的单店品牌，即使月营业额不超过 30 万，若已处于当地精品蛋糕品牌前 30%，应优先视为成长阶段而不是“建立成交”。

### 题组 C：渠道

1. 自评：基础缺失 / 单渠道较强 / 多渠道齐全。
2. 营业额占比估算：自有小程序、美团外卖、闪购外卖、美团团购、抖音团购、其他渠道。合计应接近 100%。
3. 校正规则：
   - 上述数字渠道合计低于 20%，或没有任一渠道超过 5%：基础缺失。
   - 至少 3 个数字渠道各占 5% 以上，且最大单渠道不高于 60%：多渠道齐全。
   - 其他情况：单渠道较强。
4. 显示自评与数据判定是否一致，数据优先。

## 非必填经营指标

可收集毛利率、人力成本率、食材成本率、净利率。它们只生成“需核查”的经营信号，不用单一通用阈值做强结论；应结合品牌价格带、自制比例、门店数和口径复核。

## 九宫格阶段判定

横轴不是营业额分档，而是经营阶段：

- **0-1 起步**：仍在验证产品、渠道和稳定交付。
- **1-10 成长**：已有可重复成交链路，需要建立本地心智、复购和效率。
- **10-100 资产化**：需把产品、会员、供应链和组织能力沉淀为可复制资产。

判定时的证据优先级：

`local_percentile + operation_and_store_count > revenue_band > channel_stage`

可使用以下默认校正：

- 连锁，或月营业额 100 万以上且当地前 50%：倾向资产化。
- 当地前 30%：至少判为成长，除非有明确证据表明成交链路尚未成立。
- 小型连锁、月营业额 30 万以上或当地前 50%：倾向成长。
- 其他情况默认起步，但要显示信心度和冲突证据。

## 输出契约

输出一个结构化诊断：

```yaml
brand_profile:
  city: ""
  market: high|mid|low
  market_confidence: high|medium|low
  revenue_band: ""
  operation: single|small_chain|chain
  store_count: 0
  local_percentile: top30|top50|top80|tail
  channel_self_rating: missing|single|complete
  channel_calculated: missing|single|complete
  channel_evidence: []
  financial_signals: []
grid_position:
  market: high|mid|low
  stage: start|grow|asset
  evidence: []
  counterevidence: []
  confidence: high|medium|low
```

不要输出月度任务，不要询问计划月份，不要用财务指标单点覆盖本地竞争位置。
