# 蛋糕品牌渠道增长武器库

拉新是目的，不是任务板块。你的任务是把每个上新或节日项目转成“在哪个渠道，用什么产品，做什么动作，如何验收”。

不得输出“多渠道转化”“价格纪律检查”“公私域联动”等无法直接执行和验收的词。如果确实有三件事，就拆成三条任务。

## 渠道心智

| 渠道 | 用户心智 | 优先承接 |
|---|---|---|
| 小红书 | 审美、口味、体验、打卡和本地生活决策 | 口味蛋糕、同口味切块、门店场景、正价新品种草 |
| 抖音团购 | 短平快、低门槛、强视觉刺激和即时成交 | 49.9 元以下流量品、低价套餐、代金券；外部达人不带正价蛋糕和礼盒 |
| 美团点评 | 本地搜索、到店决策、核销和口碑 | 收藏打卡、团购套餐、流量品、授权内容同步、真实评价运营 |
| 外卖 | 即时需求、搜索转化和履约 | 菜单结构、钩子产品、点金、评分与交付 |
| 私域 | 已有信任、存量激活、复购和社交裂变 | 1v1、朋友圈互动、拼团、砍价、限量券、生日和庆祝需求 |

## 小红书武器库

### 1. 自有账号体验官招募

- 奖励为大蛋糕。
- 日常上新 5-10 人，大活动 20-30 人。
- 招募笔记内嵌私信引导加企微流程。
- 置顶评论可加“参与评论即可领取小甜品”，用于增加私域转化量。
- 验收：报名、符合条件人数、加企微、到店/领取、发布、内容回收和赠送成本。

### 2. 自有账号抽奖

- 不送蛋糕，送实物奖品。
- 用户需要互动，或参与话题发布笔记。
- 适合话题扩散，不要与体验官招募合并成一件事。

### 3. 自有账号杀糕大会邀请

适合强视觉、可线下集中体验的新品或节点。单列报名、场地、产品、拍摄、私域承接和发布验收。

### 4. 外部付费博主探店

- 日常上新 3-10 人，大活动 10-30 人，按当月推广强度取舍。
- 主要服务口味、审美、体验和门店心智。
- 中秋、春节刚需礼盒默认不使用；只有新品类教育、强视觉创新或新市场认知建设时例外。
- 验收：筛号、档期、brief、探店、发布、费用、收藏/私信/加企微/成交。

### 5. 外部置换博主探店

不支付推广费，赠送蛋糕换笔记。必须与付费博主分开立项、分开统计；验收赠送成本、发布率和后续成交。

### 6. 自有账号笔记投聚光

每月的活动笔记和上新海报笔记原则上都投。记录曝光、点击、私信、加企微和成交，不只看点赞。

## 抖音团购武器库

1. **品牌大播**：只在已确认的大活动、年中、年末或周年庆节点使用。
2. **日常平播**：建议每周一场，每场 1-2 小时。属于常规动作，不必进入本月核心。
3. **流量品促销引流**：售价低于 49.9 元，如小甜品、甜品盒子、裸蛋糕。
4. **套餐/代金券促销引流**：折扣低于 8.5 折，必须同时检查毛利、核销和连带。
5. **外部付费达人探店带货**：每次 3-5 人，只带流量品；正价口味蛋糕、中秋礼盒和春节礼盒不作为外部达人带货品。
6. **本地推**：短周期庆祝性节日期间可翻倍；中秋、春节不做节日加码。

抖音验收优先看：直播时长与成交、团购销售与核销、达人实际带货、广告花费与成交，不把播放量当作唯一结果。

## 美团点评团购武器库

只有线下店时才使用到店动作。

1. **用户收藏打卡有礼**：设置明确礼品、库存、核销和统计；不与评价激励混用。
2. **评价维护**：围绕真实顾客的体验、回复、低分原因和门店改进。不做虚假评价、虚假补单或评价诱导。
3. **推广通**：节日或开业前使用，必须绑定具体产品、套餐或打卡项目。
4. **小红书付费博主笔记同步**：取得授权后免费同步，不重复购买同一内容。
5. **流量品促销引流**：售价低于 49.9 元。
6. **套餐/代金券促销引流**：折扣低于 8.5 折，同时检查毛利和核销能力。

## 外卖武器库（美团外卖/闪购外卖）

1. **门店健康度诊断**：检查是否存在平台踩雷指标。按季度或出现异常时执行，不每月重复。
2. **点金广告**：日常做关键词和预算调优。短周期庆祝性节日前 3 天每天增加 60 元、节日当天拉高至 300 元；中秋、春节不做节日加码。
3. **外卖评分运营**：通过真实订单的产品、包装、时效、售后和客诉改善评分。不执行虚假外部补单。
4. **菜单结构调整**：增加钩子产品，并检查流量品、利润品、正价蛋糕的层级和连带。

## 私域武器库

“个微群发”和“企微群发”统一写为 **1v1 群发**，不区分工具。

1. **朋友圈转发海报送产品**：用于上新预热、存量激活和社交扩散。
2. **朋友圈蛋糕征名**：适合口味蛋糕上新，不给刚需礼盒硬套。
3. **朋友圈点赞送产品**：设置简单参与门槛、限量和核销边界。
4. **邀好友拼团秒杀**：折扣低于 7 折，售价通常不高于 49.9 元。
5. **邀好友砍价 0 元秒杀**：邀请 5-10 位好友砍价成功可 0 元得，产品价值通常为 50-120 元。
6. **限量抢购半价/买一送一券/试吃券**：活动期间可每天定时定量释放额度，并按人群做 1v1 差异化触达。这是活动库存节奏，不是对用户名单逐日滚动运营。

全量营销型 1v1 群发默认每月不超过 3 次。生日服务、售后和“上月新客一转二”等特定人群批次可单独处理，但必须做受众去重和频次控制，不能用“定向”规避打扰。

## 选择规则

1. 先明确项目和产品，再选渠道；不先选渠道再硬塞产品。
2. 每个上新至少判断一次私域存量激活或裂变，从 1v1、转发有礼、点赞、征名、拼团、砍价、限量券中选 1-2 个，不全部使用。
3. 体验官和本地博主是两件事，付费博主和置换博主也是两件事，分开立项和验收。
4. 中秋、春节靠长周期消化，不套短期爆发的博主、达人、点金和本地推加码。
5. 渠道动作必须与上架日倒排，不允许“月内完成”这种无锚点排期。

### 渠道缺失机会

某渠道营业额占比为 0 时，先判断是“未开通”、“已开通但无成交”还是“品牌当前不适合”。只在城市渠道机会、产品承接和履约能力同时成立时，把“开通一个可成交渠道”纳入经营计划。不一次性补齐所有渠道。

渠道开通不能只写“开外卖”或“开团购”，应包含：资质与建店、产品/菜单结构、物料、价格与核销、测试订单或测试核销、首月基线数据。

```yaml

  - project: ""
    channel: xiaohongshu|douyin|dianping|delivery|private
    action: ""
    product: ""
    start: YYYY-MM-DD
    end: YYYY-MM-DD
    trigger_or_reason: ""
```

一条动作只表达一件事。验收指标要优先使用可数数据，并能向上追溯到具体上新项目。
