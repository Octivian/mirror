## 本轮踩到的坑与解法（已写进 alic-daily-topics skill）

1. **长文本拼进 JS 字面量会让注入静默失效**：把预期正文直接写进 `execute javascript` 做逐字比对，返回 **`missing value`**（连 try/catch 都拦不到），看着像元素没找到，其实脚本根本没跑。**改成两段短 JS**：读 `innerText` 回 Python 比对 → 再发短脚本点按钮。一次修好。
2. JS 里**不能出现双引号/反斜杠**（AppleScript 双引号字符串扛不住）；带引号的 CSS 属性值（`a[href*="/status/"]`）要换成 `a[href]` + `indexOf` 过滤；换行用 `String.fromCharCode(10)`。
3. **复核 thread 必须新开标签读主帖 permalink**——`location.reload()` 之后 X 只渲染主帖，续帖不再加载，轮询也没用。
