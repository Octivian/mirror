## 四、会员体系现状（老板问卷）

**基础状态**：已有会员体系并在运行；入会方式 = **注册即会员**（留手机号／微信）。

| 会员功能 | 已用 | 未用 |
|---|---|---|
| 会员等级 | ✅ | |
| 储值 | ✅ | |
| 优惠券 | ✅ | |
| 新人礼 | ✅ | |
| 会员日／会员价 | ✅ | |
| 积分（获取／消耗） | | ⬜ 未启用 |
| 沉睡唤醒／召回 | | ⬜ 未启用 |

**已了解／尝试过的玩法**：会员日（如周二 88 折）、会员价（指定商品会员专享价）、储值赠额。
**完全没碰过的玩法**：积分抽奖、积分抵现、付费会员卡。

**老板自述**：
- 对会员运营的理解 → 「提高会员复购率，倾听到会员真实的意见和想法，以及更好的照顾到老会员」
- 最大困难 → **「不知道怎么做，没思路」**（单选，未选"没有专人负责""系统工具不会用"）
- 目标（全选）→ 提升复购率／提高客单价／唤醒沉睡顾客／提升品牌忠诚度
- 目标补充原话 → **「不因为老板的不在店，而忽略到老顾客的照顾和体验」**
- 预算 → **「还没想好」**（非"暂无预算"）
- 同行标杆 → **「无」**（Q16／Q17 均答无，说明本地尚无对标意识）

**已落地运行的参数（10-11 沟通会复核）**：
- 会员价**限制条件**：需**储值余额** + 仅 **V2／V3** 等级可用 → 非储值会员完全享受不到，与"会员价"名字相悖
- 等级门槛：新手玩家 0 / 进阶玩家 **588** / 资深玩家 **1,000,000**（第三档门槛数值异常，见第八章）
- 会员日：每周二，甜品 & 面包 9 折（**面包已下架**）
- 新人礼：50-2 元券

> **给提案的直接启示**：客户不缺工具、不缺功能开关，缺的是**思路 + 排期 + 有人执行**。提案重点应是"给一套能落地的会员运营动作清单和节奏"，而不是推荐 SaaS 系统。预算未定 = 需要用**低投入高确定性**的首月方案建立信任。

## 七、阶段判断（2026-10-16 更新）

> 以下为现场调研（9.29）与提案沟通（10.12）后的**定稿判断**，替代此前"提案前"的初步版本。

1. **单店高利润、低杠杆**。8 月净利率 35.74%（报表口径，⚠️ 见第八章自洽性存疑），收入几乎全部来自单店堂食。任何堂食波动都直接打到利润。
2. **会员盘子大、活性极低**。注册会员 16,518 人、会员贡献 83.86% 年度消费，但 **74.97% 处于即将流失+流失状态**；30 天新增会员复购率仅 **1.4%**，累计用户中 **56% 只消费过 1 次**。→ 会员运营的第一命题是**召回与复购，不是拉新**。
3. **储值既是资产也是负债**。储值贡献 19.1% 营收、老板唯一盯的指标就是储值余额；但 **88.5% 的储值会员只充过 1 次**、储值转化率仅 7.37%。→ 储值复充机制是现金流抓手。
4. **触达通道已近失效**。个微群发被微信风控、领取率 8.1%；订阅消息仅 219 人订阅；公众号停更 3 年、小红书停更 3 个月、抖音近 1 月未更新。→ **企微 + 分层触达**是方案前置条件。
5. **本地竞品会员运营普遍空白，某复合烘焙C有先手**。8 个品牌实地调研，多数"单点动作、缺体系、店员不主动"。某复合烘焙C有产品优势 + 会员基础 + 线上热度，**机会点在体系化运营**（P13 结论）。
6. **老板缺思路，不缺预算意愿**。「还没想好」而非「暂无预算」→ 提案采用**四阶段（基建→储能→引燃→收尾）+ 首月可验证动作**的结构。
7. **决策链（提案建议口径）**：方案中按 **刘总、赵总** 为决策人、门店一线负责 SOP 落地来设计配合要求（P41）。⚠️ 属**我方在方案中提出**的分工建议，**客户是否确认待定**（见第八章 #13）。

## 十、提案方案框架（2026-10-12 沟通会）

来源：会员运营解决方案沟通会-确定版-1011 P30–P38

### 10.1 底层公式

> **营业额 = 消费会员数 × 消费频次 × 客单价**

- **新客增量**：看见 → 到店 → 沉淀（内容平台 / 团购 / 门店场景 / 新人礼）
- **老客复购增量**：再来 → 多来 → 多买（分层触达 / 会员日 / 积分 / 储值 / 产品组合）
- **总增长 = 新客增量 + 老客复购增量** → 前端补增量入口，后端补复购机制（P32）

### 10.2 四阶段路径

| 阶段 | 核心目标 |
