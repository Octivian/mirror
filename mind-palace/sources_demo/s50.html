# MacPetMVP

一个 macOS 桌面电子宠物 MVP，参考老式桌宠的悬浮形态：

- Dock 常驻的原生 macOS App
- 透明无边框悬浮窗口
- 支持同时出现多只宠物
- 右键菜单触发 10 个左右动作
- 点击摸头、拖拽有简单互动
- 默认加载 Lucky 平面素材包
- 预留自定义宠物素材包导入

## 运行

```bash
cd /Users/a15608/Desktop/MacPetMVP
swift run
```

## 打包成 `.app`

```bash
cd /Users/a15608/Desktop/MacPetMVP
./scripts/build-app.sh
open MacPetMVP.app
```

## 自定义宠物素材包格式

选择一个文件夹，里面放 `manifest.json` 和透明背景图片帧：

```json
{
  "name": "My Cat",
  "actions": {
    "idle": ["idle_01.png", "idle_02.png"],
    "petHead": ["pet_head_01.png", "pet_head_02.png"],
    "walkTop": ["walk_01.png", "walk_02.png"],
    "yawn": ["yawn_01.png"],
    "stretch": ["stretch_01.png"],
    "sleep": ["sleep_01.png"],
    "lookAround": ["look_01.png"],
    "pawScreen": ["paw_01.png"],
    "jump": ["jump_01.png"],
    "sit": ["sit_01.png"],
    "dragged": ["dragged_01.png"]
  }
}
```

动作名固定为：

`idle`, `petHead`, `walkTop`, `yawn`, `stretch`, `sleep`, `lookAround`, `pawScreen`, `jump`, `sit`, `dragged`
