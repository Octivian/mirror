# 平面设计

把这个 Skill 当作平面设计风格分区和路由入口。它不替代具体风格 Skill，也不重写各风格的生成规则。

## 风格目录

| 选项 | 调用 Skill | 适合的需求 | 核心视觉 |
|---|---|---|---|
| A. 高级杂志海报 | `$advanced-poster-maker` | 极简海报、杂志感、Zine、诗意封面 | 大留白、纸张质感、小型视觉锚点、克制高饱和色 |
| B. 解构照片图片风格 | `$deconstructed-photo-style` | 已有照片的艺术重构、摄影与抽象图形拼接 | 原照片区域、抽象记忆面板、诗意英文标题 |
| C. Mono Color 单色印刷 | `$mono-color` | 单色或双色海报、孔版印刷、网点照片、编辑视觉 | 一至两种印刷色、机械网点、留白、强字体关系 |

`$imagegen` 是这些风格常用的图片生成引擎，不作为独立风格选项。公众号排版、Figma、PPT 等相邻工具不放入本分区，除非用户明确要求扩展目录。

## 路由流程

1. 先判断用户是否已明确说出风格名称、选项或清晰视觉特征。
2. 已明确时，直接调用对应 Skill，不重复询问。
3. 未明确时，用一句话给出 A、B、C 三个选项，并结合用户素材指出各自最明显的差异，再询问用户选择哪一个。
4. 用户表示选不出来、都可以、想看看差异时，询问：是否要保持同一主题、文案、尺寸和原始素材，让三种风格各生成一张进行对比。
5. 只有用户确认后才能进行多风格生成。图片生成通常有额外时间和 API 成本，不要默认批量出图。
6. 用户确认对比后，分别调用三个具体 Skill，并保持变量一致：主题、文案、尺寸、主体素材、信息层级和交付格式相同，只改变风格系统。

## 简短询问模板

当需求模糊时优先使用：

> 这次想用哪种平面风格：A 高级杂志海报、B 解构照片图片风格、还是 C Mono Color 单色印刷？如果你选不出来，我可以先跟你确认是否按同一内容各出一张做对比。

如果用户提供了照片，补充指出 B 更强调保留并解构原照片，C 更强调把照片转成网点印刷，A 更强调大留白和编辑感。

## 对比交付

多风格对比时按 A、B、C 排列，每张图标明风格名。先展示图片，再用不超过三行说明构图、颜色与适用场景差异。不要在生成前把用户已经给出的主题、文案、尺寸或素材再问一遍。

## 边界

- 用户指定某一风格时，以该具体 Skill 的要求为准。
- 不混合三套风格，除非用户明确要求融合。
- 不把模糊的“做一张图”直接解释成三张图。
- 不因用户没有选择就停住；先给出最短、最容易理解的选择问题。
