# 客户交付 PPT 版式规范（空模板）

你只负责**排版**。不写内容、不改结论、不调整数据。内容没定稿就不要进这个技能。

**规范主轴＝复盘版**（Mirror 2026-09-17 裁定"按复盘"）。主轴数值取自 `~/Desktop/某蛋糕品牌A/某蛋糕品牌A 开业复盘&工作沟通会-0710.pdf`（65 页，实测）。
提案版差异见**第八章**——做提案类交付物时按那一章替换对应数值，其余规则不变。

**一条铁律：一页一个结论。标题写结论，不写空泛名词。** 版式做的是"让结论一眼被看到"，不是"让页面好看"。

## 二、设计令牌

### 2.1 色板

| 用途 | 值 | 用在哪 |
|---|---|---|
| **结构主色** | `#EA4809` | 色块、全宽横线、章节线、数字、强调 |
| **辅橙** | `#EC7C30` | 小结橙框、图表主色、块状强调 |
| 主文字 | `#000000` | 页标题、正文（绝对主力） |
| 数据强调 | `#FF0000` | 要盯住的那个数字/那句话 |
| 次级灰 | `#595959` | 说明、次要文字 |
| 浅橙·表头 | `#FAE4D5` | 表格分组表头 |
| 浅橙·表头浅阶 | `#FBE3D5` | 表格次级表头 |
| 深橙·强调行 | `#F4B083` | **同比行 / 环比行整行** |
| 深橙·表头 | `#F4B382` | 汇总列表头 |
| 浅灰·底 | `#F1F1F1` | 标题条、浅底块 |
| 浅灰·线 | `#D9D9D9` | 分隔 |
| 章节数字 | `#D8D8D8` | 225pt 背景数字 |

**颜色纪律**
- 结构色只有一种橙 `#EA4809`；`#EC7C30` 是它的辅阶，只用于**橙框和图表**。
- **红 `#FF0000` 是数据强调，一页最多用一次**（可以给同一个句子里的两个数字，但不要满页红）。
- **不要出现 Office 默认蓝 `#5B9BD4` / `#DDEBF7`**——那是没改过的 Excel 图表色，属历史遗留，不要继承。
- 另有两个从提案遗留的棕系（`#643E2F` / `#746256`）在复盘里出现极少，**新做时不要用**。

### P0 封面

**空模板**（复盘版，白底简版）

```
[白底]                    x=0    y=0    w=13.33 h=7.5    #FFFFFF
[联合 logo 图]            x=0.75 y=0.96 w=2.58  h=0.78
[【主标题】40pt #000000]  居中，y=2.96
[【出品方】28pt #000000]  x=8.96 y=5.79 w=2.33  h=0.49  「情绪大脑出品」
[橙色短横线]              x=7.38 y=6.05 w=1.35  h=0.04  #EA4809
```

填充规则：主标题＝`客户名 + 交付物类型`（如「某蛋糕品牌A 开业复盘&工作沟通会」，`&` 用 Arial）。右侧橙线＋出品方为一组，是收尾标记。

**变体**：提案版是**满版设计图**（1840×1080 等比铺满，文字做进图里）。
> ⚠️ 不要去抄提案 slide1 里那组封面文字坐标——它们被满版图盖住，是无效图层。

### P1 目录

**空模板**（无页眉，白底）

```
[【目录】40pt #000000]  左对齐    x=1.92 y=3.53
四条条目（行距 1.18，首行 y=1.82）：
  [【0i. 段名】28pt #EA4809]  左对齐   x=4.53
```

填充规则：段名 2—5 字（动词短语，如「开业工作复盘」「数据回顾」「问题与建议」「季度工作安排」）。**就用四段固定结构，不要另起名目。**

### P2 章节分隔

**空模板**（复盘版：带顶部全宽横线与 logo）

```
[左上 logo]                    x=11.22 y=0.24 w=1.69 h=0.51
[顶部全宽横线]                  x=0.01 y=0.86 w=13.32 h=0.06  #EA4809
[超大数字 0i+1]  225pt #D8D8D8 居中   x=0.29 y=3.45 w=3.90 h=3.96
[【章节名】]     54pt #000000 左对齐  x=6.52 y=4.89 w=4.50 h=0.95
[章节名下方橙线]  直线（cxnSp）        x=4.74 y=6.13 w=7.67 h=0.04  #EA4809
```

> 三件事必须做到：
> 1. **数字压在左下角出血**（下沿超出页面）——这是版式最强的识别点，不要挪位、不要缩小。
> 2. **章节名下方那条橙线必须画**。它是直线连接符（`cxnSp`），不是矩形。
> 3. 章节名下的橙线**从 x=4.74 起、一直拉到 12.41**，比章节名本身长得多——这是刻意的。

### P3 引语/观点

**空模板**（无页眉，白底）

```
[【引语】]    40—48pt #000000 居中   y=2.2 → 3.2
[【展开句】]  20—22pt 左对齐         y=3.9 → 5.6
```

变体（金句页）：单行大字 27—29pt，居中，配下方橙线（`#EA4809`）。

填充规则：一页只放一个判断。引语 ≤30 字；展开句 ≤80 字，分 2 个短段。

### P4 标准内容页

**空模板**

```
[页眉四件套]  （页标题 24pt #000000）
[【导语句】]  18pt，**居中对齐**，y=1.33 → 1.61
             句中要强调的数字改 #FF0000
[主体区]      y=1.9 → 6.5
[【口径注】]  8pt #595959，**右下角、右对齐**，可两行，y≈6.5 → 6.9
```

**导语句是最容易被跳过、但最重要的一行**：它是这一页的结论。**复盘版的导语是居中**，不是左对齐。全页只强调一处（一处可以含两个数字）。

主体区按内容选下面任一种（同一页只用一种）：

| 主体形态 | 说明 |
|---|---|
| **数据表格** | 见下方「数据表格样式」，复盘类交付物最常用 |
| 文字块 | 2—4 个短段，段间空 0.2，每段 ≤60 字；用 `•` 引导段，`▪` 引导条目 |
| 左文右图 | 文 x=0.75 w=5.5；图 x=6.8 w=5.5 |
| 上图下文 | 图 y=1.7 h=3.4；文 y=5.3 |

#### 数据表格样式（复盘版，必守）

| 部位 | 底 | 字号 |
|---|---|---|
| 分组表头（商城/美团/抖音/外卖…） | `#FAE4D5` | 12pt |
| 次级表头 / 分组内小表头 | `#FBE3D5` | 12pt |
| 汇总列、需要盯住的表头 | `#F4B382` | 12pt |
| **同比行、环比行** | **整行 `#F4B083`** | 11pt |
| 数据行 | 白底 | 11pt |
| 左侧「时间」列表头 | `#FAE4D5` | 14pt |

- 表格**不画竖线**，靠底色分块。
- 列位置参考（英寸）：时间 0.74 ｜ 第 1 组 1.91 / 2.91 ｜ 第 2 组 3.90 / 4.73 ｜ 第 3 组 5.58 / 6.46 ｜ 第 4 组 7.38 / 8.32 ｜ 汇总 9.38 / 10.43 / 11.48。
- **口径注放右下角右对齐**，不要放左下。

> **"同比行整行橙底"是这套版式最强的识别点之一**，做数据页时优先保留。

### P6 数据条对比

**空模板**（按期次逐行，行距 1.18，首行 y=2.68）

```
每行 i（y = 2.68 + 1.18i）：
  [期次标签]   12.5pt #000000 左对齐   x=0.95 w=1.00 h=0.22
  [条形底]     fill #FFFFFF 描边 #D9D9D9     x=2.05 w=3.30 h=0.28
  [条形填充]   基色 #EC7C30，强调行用 #EA4809 x=2.05 w=(比例×3.04) h=0.28
  [数值]       10pt 同条形色            x=5.50 w=0.70 h=0.20
  [【指标说明】] 9.5pt #595959          x=2.05 y=+0.44 w=3.30 h=0.20
  ── 右侧第二组（同一行第二个指标）──
  [条形底/填充/数值/说明] x=6.15 / 6.15 / 9.60 / 6.15
  [【代表品名】] 9.5pt #000000          x=10.15 y=+0.03 w=1.80 h=0.24
```

填充规则：**只在期初期末都用同一口径时才能画在同一页**。条形长度＝数值 ÷ 该组最大值 × 3.04。

### P13 建议页

问题页系列的最后一页，专门放"建议——"。**全页居中排版。**

```
[页眉四件套]  （页标题 20pt #000000）
[引导词]   「建议——」20pt #FF0000 居中    y≈2.2
[【结论句】] 24pt #000000 居中             y≈2.9
[【说明行 ×2】] 16pt #000000 居中          y≈3.3 / 3.7
```

填充规则：结论句＝一句可执行的主张，句中要强调的词改 `#FF0000`；说明行做「内部视角」「用户视角」这类对照，每行 ≤45 字。

### 问题页三页式（复盘类交付物通用）

一个问题占 **3 页**：

| 顺序 | 页 | 内容 |
|---|---|---|
| 1 | 现象页 | 一句话把问题说清（页标题 20pt，如「问题1：研发"纠结"」） |
| 2 | 证据页 | 数据 / 现场 / 访谈，至少 2 类 |
| 3 | **P13 建议页** | 「建议——」+ 结论 + 说明行 |

一个问题占 3 页，所以**问题数控制在 3—4 个**，宁少勿杂。

### 4.1 复用 helper 出实稿（实战：某蛋糕品牌A Q3 初版）

**做法**：把 `references/build_template.py` 里的 helper 整段复制到新脚本，只改 `LOGO` 路径，然后逐页写内容。不要重写 helper。

可复用的 helper：`S()` 新建页 / `rect()` / `tb()` 文本框 / `logo()` / `header()` 页眉 / `lead()` 导语 / `note()` 脚注 / `ph()` 占位框 / `section()` 章节页 / `table()` 数据表。

**`table()` 的两处关键实现**（实稿必用）：

```python
# ① 去边框：python-pptx 没有边框 API，往单元格 XML 插空线
tcPr = cell._tc.get_or_add_tcPr()
for tag in ('a:lnL','a:lnR','a:lnT','a:lnB'):
    for old in tcPr.findall(qn(tag)): tcPr.remove(old)
for tag in ('a:lnL','a:lnR','a:lnT','a:lnB'):
    ln = tcPr.makeelement(qn(tag), {'w':'0','cap':'flat'})
    ln.append(ln.makeelement(qn('a:noFill'), {}))
    tcPr.append(ln)

# ② 用 '!' 前缀标记红色强调单元格，省掉逐格传参
if txt.startswith('!'): txt = txt[1:]; col = C_RED; bd = True
```

**防重叠算法（必做，否则一定压边）**
- 表格渲染高度 ≈ `rowh × 行数`（内容多时会被撑高，要留余量）
- **后续元素起点 ≥ 表格起点 + rowh × 行数 + 0.1 in**
- 每页做完按这个式子自查一遍；一页最多约 10 行表格 + 2—3 行说明

**预览校验（每次生成后必跑）**

```bash
soffice --headless --convert-to pdf --outdir /tmp/out <pptx>
```
```python
import pymupdf
d = pymupdf.open('/tmp/out/xxx.pdf')
for i in range(d.page_count):
    d[i].get_pixmap(dpi=140).save(f'/tmp/out/d{i+1:02d}.png')
```
拼一张 3 列网格总览图（扫结构与一致性）＋ 2—3 张关键页细节图（看表格是否溢出），两者一起看。

**「结构验证稿」这个例外**：内容未定稿时，若使用方明确要求"先给一版看结构"，可以出稿，但必须满足两条——① 缺数据的页用**红色占位框**明确标出（不留白、不编数）；② 文件与预览图命名带 `初版`，交付时说明哪些是真数、哪些是占位。

实战产出：`某蛋糕品牌A/04-复盘/某蛋糕品牌A_Q3经营复盘_20260924_v0.1.pptx`（27 页）＋ 脚本 `_build_q3_v0.1.py` ＋ 预览图。

### 4.2 从零生成

1. **内容定稿**。上游技能（如 `cake-client-review`、`customer-full-case-marketing-proposal`）先出结构化内容稿，逐页标好：页型代号 + 页标题（结论句）+ 导语句 + 主体内容。
2. **版式映射**。按第三章把每页装进对应页型。装不下的内容，**拆页，不要缩字号**。
3. **生成**。
   - 走 `tencent-pptx`：把本规范作为版式要求一并传入。
   - 走 python-pptx：按第二章令牌 + `references/geometry.md` 的坐标表逐元素落位。
4. **自检**（见第六章）。
5. **交付**。文件名带客户名 + 交付物类型 + 日期 + 版本。

## 八、提案版差异（做提案类交付物时用）

提案（`某蛋糕品牌A提案确定版.pptx`）与复盘**是同一套设计语言，但数值不同**。做提案时，把主轴里这几项替换掉，其余不变：

| 项 | 主轴（复盘·开业复盘实测） | 提案版 |
|---|---|---|
| 结构主色 | `#EA4809` | `#E84B12` |
| 左上色块 | 0.09 / 0.27 / 0.44×0.44 | 0.08 / 0.22 / 0.43×0.43 |
| 全宽横线 | y=0.86 h=0.06 | y=0.88 h=0.03 |
| 页标题 | **24pt `#000000`**（问题页 20pt） | **21pt `#231D19`**，全篇统一 |
| 右上 logo | 11.22 / 0.24 / 1.69×0.51 | 11.15 / 0.20 / 1.82×0.55 |
| 导语句 | 18pt，**居中**，黑+红 | 16pt `#663A2B`，**左对齐** |
| 封面 | 白底简版 | 满版设计图 |
| 目录 | 「目录」40pt ＋ 四行 28pt `#EA4809` | 四行：编号＋段名＋短线＋说明 |
| 章节页 | 带顶线＋logo，章节名左对齐 x=6.52 | **无 logo、无顶线**，章节名右对齐 x=8.63 |

| 卡片系 | `#F1F1F1`/`#D9D9D9`/`#000000` | `#FFFAF2`/`#DECDBC`/`#643E2F` |

> 两版都**不该继承**的东西：提案自己用了三个几乎一样的橙（`#E84B12`/`#EA490A`/`#EA5C24`）；开业复盘的页标题字号有四种、章节名对齐方式不统一。**规范里给的是归一化后的整数刻度，照规范做，不要照原文件做。**
