## 二、已确认事实

### 1. 品牌与发展阶段

- 品牌：某蛋糕品牌A，徐州本地蛋糕、甜品和下午茶品牌。
- 约2019年从双人私房工作室起步，老板本人制作蛋糕。
- 2021-2024年经营较小规模线下店，兼顾下午茶打卡和生日蛋糕。
- 2024年搬到现址，加强下午茶和门店打卡场景。
- 2024年末开始重点经营抖音，通过直播和低价小四寸蛋糕拉高销量。
- 2025年下半年逐步发现抖音购买习惯、核销表现和低价低利润问题，随后减少大规模直播。
- 2026年4月暂停周年庆，5月开始重装楼下堂食店。

### 2. 流量与渠道资产

- 老板小红书账号约2万粉丝，微信好友约4万。
- 老板愿意出镜，有个人IP基础；内容质量较好，但互动和成交承接偏弱。
- 美团、抖音、外卖和小程序均已开通，平台基础建设总体具备。
- 历史信息显示抖音人气榜第4、点评热门榜第5；排名具有时效性，使用前需重新核验。
- 小程序曾存在不能直接添加客服微信、甜品SKU显示售罄等承接问题。

### 3. 团队与经营基础

- 团队年轻、积极性和主动性较好。
- 内部标准化基础较弱，特别是新品研发、报单、出单和运营协同流程。

## 三、数据结论

### 0. 中秋月饼销售基准

- 2025年中秋月饼销售营业额约40万元。
- 2026年中秋目标必须实现同比增长，但具体目标仍需结合去年渠道/SKU结构、今年客群规模、礼盒毛利和后厨产能测算。
- 9月对某蛋糕品牌A不是普通时令上新月，而是年度月饼销售大月；月饼礼盒应成为9月唯一经营主线，避免秋季蛋糕甜品同期分散资源。

### 1. 抖音近12个月分析

- 2026年1-5月抖音成交金额约从23.1万元降至8.4万元。
- 同期成交人数约从2471人降至938人。
- 成交客单大体保持在89-98元，主要问题是购买人数下降，而不是客单价崩塌。
- 奶皮子四寸、草莓5选1、油画玫珑等爆品先后衰退，新爆品没有连续接档。
- 2026年小四寸/四寸尝鲜类长期占据较高成交份额，限制利润和高客单承接。
- 六寸蛋糕成交从2026年1月约6万元降至5月约1.87万元，生日场景承接减弱。

### 2. 数据口径

- “前三个月实收占比”表为综合口径，可用于目标拆解。
- 其他不少经营数据主要来自有赞或小程序，不能直接代表全渠道。
- 后续所有分析必须先确认时间范围、成交/实收口径、渠道范围、退款及核销口径。

## 四、阶段性战略判断

### 1. 核心命题

- 某蛋糕品牌A不是缺流量，而是缺少把流量稳定转化为产品资产、客户资产和利润的能力。
- 长期目标是成为徐州蛋糕市场的领先者和常青树，而不是依赖短期平台爆品。
- 长期品牌规划的工作主张：品牌竞争不只是更早感知消费者变化，而是从变化中识别值得长期回应的意图，并持续把它变成可感知、可购买、可复购的产品与体验。
- 某蛋糕品牌A的长期课题应由“获得更多曝光”转向“在某个需求发生时，消费者为什么更愿意先选某蛋糕品牌A”。渠道补齐、用户触达和上新提速都应同时承担需求验证与品牌资产沉淀任务。
- 当前候选需求方向包括“重要时刻的可靠且有审美的蛋糕选择”和“一至两人日常犒赏、不过量但有仪式感的小规格蛋糕”，尚需通过用户、交易和复购数据验证，不直接作为最终品牌定位。

### 2. 产品

- 当前产品视觉和热门款跟进能力较好，用户评价基础不错。
- 主要问题是追逐热门款较多、稳定招牌不清晰，产品资产沉淀不足。
- 小四寸夹在甜品与标准生日蛋糕之间，挤压四寸需求，但没有形成高销量甜品带动。
- 暂定方向：逐步弱化直至取消小四寸；堂食主推切块、2/3寸甜品和下午茶；线上主推4/6寸蛋糕。
- 六寸蛋糕承担生日场景、品牌展示和利润；低门槛产品主要承担尝鲜、到店和拉新。

### 3. 渠道与价格

- 团购、外卖、抖音与小程序之间曾存在价格倒挂风险。
- 抖音负责尝鲜、到店、限量和季节性拉新；小程序负责生日、正价、完整规格、定制服务和复购。
- 不长期在抖音低价销售小程序同款同规格产品。
- 直播货盘应包含引流款、流量款、承接款、利润款和复购承接，不能只靠低价小四寸冲量。

### 4. 研发与运营

- 后厨研发缺少稳定流程，曾导致母亲节、520定版晚、打样匆忙、产品吸引力不足和宣发节奏失配。
- 新品应执行：概念与目标人群 -> 打样 -> 调整 -> 内测 -> SOP -> 成本卡 -> 定价 -> 物料与渠道上架。
- 老板需要主导“卖什么、卖给谁、怎么卖”，项目团队负责把判断变成流程和执行排期。

### 5. 内容与私域

- 内容不应只提供观看热闹，需要增加用户互动、福利承接、商品路径和复购触达。
- 约4万微信好友是重要客户资产，但激活动作需要有节奏，避免无序群发和过度促销。
- 小程序应强化下单认知、客服入口、生日场景和复购承接。

## 五、外部市场判断

- 徐州GDP、人均收入和品牌入驻情况显示消费空间较好，同时具备一定旅游和流动客群。
- 核心商圈集中，且与门店距离较近，具备流量覆盖和到达优势。
- 本地蛋糕品牌整体仍处于相对初级阶段，竞争尚未高度成熟，产品力可作为首要提升能力。
- 小红书“徐州蛋糕”关键词下，本地品牌系统投放较少，存在内容占位机会。

## 六、执行优先级

1. 建立新品研发与上新流程。
2. 梳理产品结构，建立稳定招牌和4/6寸价格带。
3. 修正渠道价格倒挂，明确各渠道分工。
4. 优化小程序、客服与私域复购承接。
5. 用月度上新、节日活动和直播持续验证，而不是一次性大改。
6. 报单设备、出单动线和产品附加价值属于重要但不紧急事项，在前四项稳定后推进。

## 七、提案表达偏好

- 面向老板的正式提案优先使用经营语言，不在主讲页堆砌SWOT、4P等框架名称。
- 叙事顺序：回到调研现场 -> 说明已经具备的优势 -> 击中关键经营问题 -> 给出少量优先动作 -> 说明首月如何落地。
- 结论需要证据支持，但避免把单渠道数据描述成全渠道事实。
- 结构化版本可用于内部审核；老板提案版本强调听得懂、被击中、知道马上做什么。
- 面向老板提出目标、产品规格、奖金和部门动作时，保持咨询顾问角色：提供制定方法、参考系数、演算示例和决策边界，不替老板直接确定真实目标或奖金金额。
- 销售目标不机械平均分给前厅、客服和后厨：前厅与客服承担销售/线索目标，后厨承担产能、准时交付、损耗和客诉目标；三个部门共同参与阶梯奖金池。

## 八点一、待验证的产品结构假设

### 小规格日常消费与六寸生日消费的矛盾

- 当前假设：用户的部分蛋糕消费可能由六寸生日场景转向四寸/三寸日常解馋场景，但现有数据尚不足以确认这是自然需求迁移。
- 已有证据只能确认：低价小四寸曾是抖音的重要成交触发器，停止后抖音购买人数和成交明显下降；同时六寸蛋糕也缺少稳定承接。
- 需要区分三种原因：真实场景迁移、平台低价心智训练、爆品及推广供给变化。
- 不能把四寸简单定义为“更便宜的六寸”。若同口味、同造型、同服务只缩小尺寸，会直接分流六寸并降低绝对毛利。
- 后续验证指标：各尺寸新老客结构、同一用户尺寸迁移、30/60日复购、四寸对六寸的蚕食率、单笔绝对毛利、单位工时毛利、每100访客总毛利。
- 暂定策略方向：少量保留有利润的标准四寸日常蛋糕；六寸继续承接生日和庆祝；三寸仅用于限量测试，不全面铺设；抖音可恢复有数量和时段限制的四寸成交入口，但不恢复过去无利润的低价小四寸。

**复盘确认的四类问题**

1. 研发决策过度纠结内部技术感受，用户对造型、拍照、口味新颖度、食材品质和夹心丰富度的视角不足。
2. 赠送活动不能只看即时ROI，应作为注意力采购，但必须先测试转化水平并建立年度预算约束。
3. 砍价产品交付、现场抽奖等卡点说明物料、人力、活动和交付流程测试不足。
4. 成本核算方式不够稳定，尚未按不同产品角色区分价格带和毛利要求。

**预算与定价规则**

- 年度营销预算建议控制在营业额的3%-5%，大活动预算约占年度营销预算的30%。
- 主推4寸产品建议价格带118-128元，含包装毛利建议65%-70%，可通过增加合理成本提升产品价值。
- 其他产品毛利可按角色在60%-75%之间浮动。
- 成本卡必须标准化；常规非季节产品建议每半年更新一次成本。
- 复盘中的普洱荔枝样例：4寸成本28.824元、定价108元、毛利约73%；6寸成本48.644元、定价188元、毛利约74%。
