# 解构照片图片风格

把用户上传的照片转化为一张完整的竖向编辑作品：上方或主要区域忠实保留摄影原片，下方使用中性象牙色抽象面板重构照片的空间记忆，并配一个原创、克制的英文标题。

## 开始前

1. 确认当前任务提供了可访问的照片。没有照片时，只追问用户上传照片，不凭空生成。
2. 完整读取 [references/style-spec.md](references/style-spec.md)，它是本风格的视觉规范。
3. 检查照片方向、宽高比、主体密度、视觉重心、重要颜色和可接受的轻微裁切范围。
4. 若用户只要求提示词，输出一份适配其照片的完整生成提示词，不调用图片工具；否则制作最终图片。

## 核心方法

始终采用：

`DECONSTRUCT -> SELECTIVE PRESERVATION -> ABSTRACT / DISTILL -> RECONSTRUCT`

在内部完成以下判断，不向用户展示冗长分析：

- 提取照片最重要的 3-6 个空间事实。
- 区分主体质量、结构轴、运动方向、重复节奏、间距、遮挡、层级、明暗、色彩角色与留白。
- 删除纹理、透视细节、背景杂讯和低信息装饰。
- 选用一个主要标记家族，最多两个辅助标记家族。
- 保留照片独有的关系和最低必要辨识度，不复刻物体表面。

## 制作流程

### 1. 保护原片

- 把用户照片作为唯一内容来源。
- 摄影区域必须直接使用原始像素，只允许克制的等比缩放或为拼接比例进行轻微裁切。
- 不让生成模型重绘、修饰、扩展或替换摄影区域。

### 2. 生成抽象面板

- 从原照片提取有限色彩和结构关系，生成独立的抽象面板。
- 面板背景使用均匀、连续的中性象牙色，默认 `#F3F0E8`，不得使用渐变、阴影、纹理或噪点。
- 只生成来源可追溯的抽象标记，不添加照片中不存在的物体、象征、颜色或装饰。
- 保持大量留白和轻微自然不规则，避免规则化信息图、通用图标和矢量描摹感。
- 调用可用的图片生成/编辑能力时，只让其生成面板，不生成或重绘整张原照片。

### 3. 命名与排版

- 根据照片真实主体关系、光线、时间、方向或运动，在内部确定一个 2-5 个英文单词的原创标题。
- 只有副标题能增加新语义时才加入 3-7 个英文单词的副标题。
- 标题使用优雅、克制的衬线字体，颜色取自照片中的深色角色，不默认纯黑。
- 标题只放在抽象面板内，根据重心选择左下对齐或底部居中。
- 使用可控的本地排版方式渲染标题，避免生成模型产生错字、重复文字或额外字符。

### 4. 精确合成

- 用本地图片合成工具把原照片、抽象面板和标题组合成单张竖向成品。
- 根据照片方向和视觉重心自适应确定照片/面板比例，遵循参考规范而非机械五五分。
- 照片与面板直接平面衔接，不加相框、撕纸、胶带、阴影、立体卡片或样机效果。
- 保持原图宽高关系，优先完整呈现主体，不为固定画布比例激进裁切。

## 验收

交付前逐项检查：

- 摄影区域与输入照片内容一致，没有被生成模型改写。
- 抽象面板中的每个主要标记都能对应照片事实。
- 第一眼是极简抽象构成，第二眼才联想到这张特定照片。
- 面板背景完全均匀，无渐变、阴影、噪点、纸纹或接缝。
- 标题准确、只出现一次，且没有其他文字、数字、日期、Logo 或水印。
- 配色全部来自照片，强调色数量克制。
- 留白、比例、对齐和边距稳定，没有元素拥挤或贴边。
- 最终只交付一张完成作品；除非用户要求，不附候选标题或分析说明。

发现摄影区域被重绘、标题错误、面板出现虚构元素或背景不均匀时，不交付该版本；回到对应步骤修正后重新验收。
