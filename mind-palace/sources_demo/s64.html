# 设计工作区 · 长期约定

## 工作方式

- **先读资料再画。** 客户资料在 `/Users/a15608/Desktop/<客户名>/`，里面有品牌、产品、渠道、经营数据。海报/物料的文字一律取自有据可查的来源，不编造产品名、日期、促销承诺。
- 品牌 Logo / VI 素材某蛋糕品牌A目录下不存在，涉及品牌标只能用文字标或占位，需向客户索取。
- 交付物默认导出 PNG 到本工作区 `outputs/`，命名格式：`<客户><物料名>_<尺寸>_<版本>.png`。

## 海报规范（Ardot canvas）

- 字号硬底线 **28px**，任何一个文字节点都不得低于此值；溢出时砍内容，不缩字号。
- 字体最多 2 款。中文优先：标题 Noto Serif SC，正文/信息 Noto Sans SC（画布已确认可用）。
- 色彩最多 3 个角色。高级极简方向固定用：底 `#F4F0E8` / 墨 `#1A1A1A` / 金 `#C49A4A`（金色全幅最多 3 处）。
- 竖版海报默认 1080×1440，四周留白 88px。
- 一个视觉焦点，其余全部退让；负空间 ≥ 30%。

## 概念可视化（对话内联图）

- 概念解释类需求走 Visualizer 的 diagram 模块，**不走海报技能**——海报技能出的是静态美术图，装不下概念之间的依赖关系。
- **分组 ≠ 关系。** Mirror 会直接说「看不到关系，依旧是罗列」。一张概念图至少要表达下面一种关系，否则就是失败的列表：**包含**（谁在谁里面）、**依赖**（谁产出谁、谁被谁用）、**角色差异**（这是零件／架构／流程／形态／规律／能力）。
- 有效骨架：按「回答哪个问题」分层，层标题写明该层概念扮演的角色，层间用箭头接因果。**不要按主题分两栏了事。**
- 她列的清单是素材不是规格——重叠项合并，跨抽象层级的项拆开另立一层。这条见 `~/.workbuddy/SOUL.md`。
- Visualizer 硬限：颜色 ≤2 ramps／图、同层横向 ≤4 盒、字号 ≥11px。层内差异靠位置和虚实表达，不要靠加第三种色相。
- SVG 不自动换行，中文按 12px 宽按「1 字 = 1 单位宽」估算，超宽就得手动断行。

## 已知环境问题

- Ardot 的 `G()` AI 生图不稳定，可能出现 fill 有 imageHash 但实际仍是 Image Placeholder 的情况。用 `download_source_media` + md5 比对确认；**不要重试 G()**，改走矢量方案。
- `curl` 下载 Ardot 返回的截图/导出链接，加 `-sS -L --retry 2`。
